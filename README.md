# ♠ Карточный круг

Сайт, чтобы играть с друзьями с телефонов. Без регистрации: вводишь ник, создаёшь комнату и кидаешь друзьям ссылку вида `/room/ABCD`.

## Как сделан сайт

Весь код сайта написан с помощью ИИ — [Claude Code](https://claude.ai/code). Я сам не писал ни строчки кода:
я придумывал, что нужно сделать, проверял игры на телефоне вместе с друзьями, говорил, что исправить,
и выкладывал сайт на Render.

## Игры

**УНО** — 2–10 игроков, есть боты
- Правила как в мобильной версии: «+2» и «+4» складываются (можно отключить в лобби), «+4» можно сыграть всегда.
- Если ходить нечем — один добор или добор до подходящей карты (на выбор в лобби).
- Кнопка «УНО!» появляется, только когда у кого-то осталась одна карта: успей крикнуть или поймать.
- Игра идёт, пока не выиграет половина игроков; на ход — минута.
- Карты в руке разложены по цветам.

**Дурак** — 2–6 игроков, есть боты
- Подкидной или переводной, колода 24, 36 или 52 карты.
- Карты в руке: козыри слева, дальше по убыванию.
- Карты, которыми можно сходить, чуть приподняты.

**Мафия** — 4–15 игроков
- Онлайн (сайт сам ведёт игру) или с живым ведущим.
- Состав ролей настраивается: сколько мафий, доктор, комиссар, маньяк. В лобби сразу видно, какой получится состав.
- Роли выбывших раскрываются.

**Задания** — 2–15 игроков
- «Правда или действие» с рулеткой: колесо с именами выбирает игрока, он выбирает правду или действие.
- Задания придумывают сами игроки или предлагает сайт (своя колода из 80 заданий для компании 17 лет).
- Кто крутит — на кого выпало, по кругу, любой или только создатель.
- Кому недавно выпадало, тому выпадает реже. Зайти можно и посреди игры.

## Что есть на сайте

- Комнаты по коду или ссылке, создатель комнаты выбирает игру и правила.
- Чат и эмодзи-реакции.
- Картой ходят двумя нажатиями или смахиванием вверх.
- Плавные анимации карт, звуки, тёмная и светлая тема.
- Если пропала связь или закрыл вкладку — возвращаешься на своё место.
- Выход из комнаты кнопкой 🚪 с подтверждением.
- Пустая комната удаляется через 20 минут.

## Запуск у себя

Нужен [Node.js](https://nodejs.org) 18 или новее.

```bash
npm install
npm start          # сайт на http://localhost:3000
npm test           # тесты правил игр
```

Порт можно поменять переменной `PORT`.

## Как выложить на Render

1. На [render.com](https://render.com) создать **Web Service** и подключить этот репозиторий.
2. Build Command: `npm install`, Start Command: `npm start`.
3. После каждого слияния в `main` Render сам обновляет сайт.

На бесплатном тарифе сайт засыпает, если на него долго никто не заходит, и первый заход потом грузится около минуты.
Комнаты хранятся в памяти сервера, поэтому при перезапуске сайта они пропадают.

## Устройство

- `server/index.js` — сервер: страницы и обмен сообщениями с игроками (Express и Socket.IO).
- `server/rooms.js` — комнаты, игроки, возвращение после обрыва связи, боты, таймеры.
- `server/games/` — правила игр, по файлу на игру. Новая игра — новый файл и строка в `games/index.js`.
- `public/` — то, что видит игрок: HTML, CSS и JavaScript без сборки.
- `test/` — тесты правил игр.
