# ♠ Карточный круг

Сайт для игр с друзьями: без регистрации, только ник и код комнаты.

| Игра | Статус |
|------|--------|
| УНО (2–10 игроков, боты, настраиваемые правила: +2 на +2, +4 на +4) | ✅ готово |
| Дурак | 🚧 в разработке |
| Мафия (онлайн и с живым ведущим) | 🚧 в разработке |

Что уже есть: комнаты по коду/ссылке (`/room/ABCD`), чат и эмодзи-реакции, звуки и анимации, тёмная/светлая тема,
реконнект после обрыва связи (по токену в браузере), боты, адаптивная вёрстка (телефон и компьютер).
Пустая комната удаляется через 20 минут.

## Запуск

```bash
npm install
npm start          # http://localhost:3000
npm test           # тесты правил
```

Порт задаётся переменной `PORT`. Через Docker: `docker build -t krug . && docker run -p 3000:3000 krug`.

## Показать друзьям без хостинга

Запустите `npm start` и пробросьте порт, например `npx cloudflared tunnel --url http://localhost:3000`
или `ngrok http 3000` — получится публичная ссылка.

## Структура

- `server/index.js` — HTTP + Socket.IO, события комнаты и чата
- `server/rooms.js` — комнаты, игроки, реконнект, боты, таймер удаления
- `server/games/` — правила игр (чистая логика: `create`, `act`, `view`, `botMove`); новая игра = новый модуль + строка в `games/index.js`
- `public/` — фронтенд без сборки
- `test/` — юнит-тесты логики
